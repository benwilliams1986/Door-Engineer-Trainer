# Contributing equipment records

1. Use an exact manufacturer and model.
2. Record product revision/software version where relevant.
3. Link the authoritative manufacturer documentation.
4. Do not guess terminal numbers, parameter values or safety behaviour.
5. Start with `verified: false`.
6. Review the model-specific lesson before setting `verified: true`.
7. Do not commit copyrighted manufacturer manuals unless redistribution is permitted; store links/citations instead.
